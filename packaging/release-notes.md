## Download

- **`GhostCue-<version>-setup.exe`**: the installer. Installs for your user only, with no administrator rights, and adds GhostCue and the teleprompter to the Start menu.
- **`GhostCue-<version>-win64.zip`**: the same app without installing. Unzip it anywhere and run `GhostCue.exe`.

Needs Windows 10 version 2004 or later, 64-bit. The assistant also needs [Claude Code](https://claude.com/claude-code), installed and signed in. The speech model downloads once, the first time you start listening.

**"Windows protected your PC"**: GhostCue is not yet code-signed, so Windows SmartScreen warns about it. Click **More info**, then **Run anyway**.
